# Typr 

Welcome to `typr`!

Typr is capable of rendering Markdown, Typst, and LaTeX documents, all in the browser, with no internet connection.  It works on mobile, too!

## Panes

There are three panes.  The left pane has tabs to choose from.  Click around to get to know them.  Notable tabs are Files (where your file tree can be accessed), Git (where you can stage/push/pull/etc), and Debug (LaTeX giving you a hard time?  Look no further).

## Settings

The settings are accessed by clicking the gear in the bottom left corner.  This is how you connect your GitHub credentials, change your theme, etc.  

## Keyboard Shortcuts

A lot of features and navigation can be done with keyboard shortcuts.  Since we're in the browser, control, and command are not used.  Instead, most shortcuts are done with alt/option.  Try a few: alt + h/j/k/l can navigate through the different panes and tabs.  Alt + mouse-wheel zooms. Alt + v enters vim mode, and alt + s/p hides and shows the source and preview panes.  Try alt+z for zen mode!

## Try it!

Try opening one of the files in the files tab and see how easy it is to compile a typst/latex document!
